# Performance evidence

No throughput or capacity claims have been made. Benchmarks will report routed
passthrough, capture, analysis, and MITM profiles independently with packet
drops, latency, CPU, memory, disk growth, and ingest lag.

The current capture VM is a functional integrity proof, not a benchmark. It
records worker-reported packet/drop totals and artifact byte growth while
verifying the final manifest. Sustained-rate, latency, CPU, memory, disk-growth,
and analyzer-lag measurements remain required before a capacity claim. The
current deterministic analyzer smoke proves integrity and replay behavior for a
seven-packet PCAPNG only; it is not throughput evidence.
