# Protocol support matrix

The Compose development profile remains setup-only. Separately gated packaged
host capabilities are listed only where a test now exists; raw capture does not
mean passive classification or plaintext visibility.

| Protocol | Raw capture | Passive classification | Proxy mode(s) | Decryption prerequisites | Known blockers | Test evidence | Status |
|---|---|---|---|---|---|---|---|
| TCP/IPv4 | Bounded lab-ingress PCAPNG after guarded activation | Zeek/Suricata consume safely closed ring rotations and reconcile against the finalized manifest; normalized records receive a device ID only for one-device timestamp/window matches; bounded metadata-only recent-event UI | None | N/A | No deep search | Ubuntu VM capture plus deterministic HTTP PCAPNG yielding 4 Zeek and 5 Suricata records; active-feed restart/finalization/loss tests; race tests cover time-aware attribution and ambiguity; query smoke covers credential separation and durable visibility | acquisition, bounded active/final passive analysis, recent-event inspection, and DHCP-window attribution |
| UDP/IPv4 | Bounded lab-ingress PCAPNG after guarded activation | DHCPv4 leases; pinned engines accept safely closed rotations and finalized captures, but UDP analysis lacks recorded integration evidence | None | N/A | No UDP analyzer fixture | Kea virtual-client lease plus capture ring proof | acquisition and DHCP attribution only |
| DHCPv4 | Visible in raw capture | MAC/client-ID/hostname/address lease evidence, local IEEE MA-L/MA-M/MA-S longest-prefix vendor evidence, and half-open validity windows used for analyzer-event attribution | Native Kea server | N/A | DHCP vendor class and discovery evidence not integrated | Kea parser, bounded IEEE CSV parser, durable attribution, conflict/IP-reuse/overlap tests | partial inventory support |
| IPv6/ICMPv6/NDP | Bounded lab-ingress PCAPNG after guarded activation, including link-local and NDP frames | Neighbor-table (NDP) MAC-to-IPv6 evidence with confidence 80 and first/last-confirmation windows used for analyzer-event attribution of SLAAC and link-local addresses | Routed lab /64 with SLAAC and RDNSS from `shakerproxy-radvd`: `ULA_NAT66_LAB` (NAT66) or `NATIVE_ROUTED_PREFIX`; `DISABLED` drops forwarded lab IPv6 | N/A (IPv6 DNS/TLS interception follows the traffic policy) | No DHCPv6 or prefix delegation; no NDP proxy; single-arm and passive plans cannot route IPv6; ULA-only devices often prefer IPv4 | Validation, golden ip6tables/radvd/Netplan rendering, apply/rollback/health unit tests, netlink parser tests, and an isolated namespace proof of SLAAC, NAT66, NDP evidence, DISABLED drop, and exact rollback; no clean-VM or physical-device run yet | experimental routed IPv6; VM and device acceptance pending |
